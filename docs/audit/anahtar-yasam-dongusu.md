## 4. Ortak notlar

- **JS dizgileri sıfırlanamaz.** `arsivAc(archiveKeyHex)`, `arsivTasi(eskiArchiveKeyHex, …)` gizli anahtarı hex dizgi
  alır; `Buffer` kopyası sıfırlanır, dizgi sıfırlanmaz. 387/388 için `{ $b }` bayt gövdesi kabul edilir (D36; `sirHex`
  eskisi). Kanal çerçevesi zaten JSON metnidir (`worklet/ipc.js`).
- **Silme ≠ güvenli silme.** `Depo.sil` `fs.unlinkSync`'tir (`worklet/persistence.js`); flash bellekte üzerine yazma yoktur.
  Koruma dosyaların platform anahtarıyla şifreli olmasından gelir.
- **Geri alma koruması.** `durum` tekdüze `sayac` taşır; uygulamanın verdiğinden küçükse `STATE_ROLLED_BACK`
  (`Kalici._durumuAc`). `arsiv` özeti `durum`'un `arsivOzetleri` listesinde olmalı (`_yanDosyalar`). `hlc` durum
  saatinden geride olamaz. `gomme/` dosyaları bu bağa girmez (İstek 139 d).
